模型参数、数据范围与科学边界

房间实验的控制来源：72 个视场通过射线读取环境亮度，人工分配给 3,377 个 R1–R6 光感受器；注释中的左右侧标签保留，但视场分配不是测得的视网膜拓扑。趋光方向来自这些细胞实际计算出的脉冲率。311 个 LC4/LPLC2 细胞接受局部距离编码，激活连接组中的下游神经元。由于 R1–R6 的快速递质作用未建模，趋光读出直接取自感受器，不经过已验证的中间视觉通路；没有使用运动神经元控制肌肉。

转向读出、距离避障、速度与高度稳定均为工程模型。室内灯使用方向响应、距离衰减和遮挡近似；移动遮挡球同时影响亮度和局部距离。闪光持续 350 ms 模拟时间。它们是人工感觉编码，并非实测感受野。自定义起点只影响下一次释放，修改灯和遮挡物会保留正在计算的神经状态。环境每 20 ms 模拟时间更新一次，没有预设轨迹或传入控制器的出口坐标。碰撞按实体包围盒和果蝇球体处理；桌下也作为障碍范围。窗户关闭仍透光，但无法通过。视野图的底部绿色条显示对应细胞的脉冲率。飞出后两侧自动暂停，保留同一时刻的结果。

食物与声音：食物气味人工编码到 148 个有左右侧注释的 ORN_DM1 / ORN_VA2 细胞，示意与食物吸引有关的两条嗅觉通路，并非水果完整气味谱。气味场使用平滑距离衰减，没有空气流动、障碍物对扩散的影响、浓度单位或饥饿状态。趋食辅助用实际 ORN 脉冲率调节局部气味梯度追踪，这是工程控制，并非已验证的嗅觉到运动神经回路，也不模拟降落或进食。关闭趋食辅助仍保留嗅觉输入。

声源人工编码到 101 个有左右侧注释、编号明确的 JO-A / JO-B 细胞，未纳入 unclear 类型或全部听觉通路。模型仅编码距离衰减、音量、频率响应和节奏包络；A / B 响应曲线是示意设定，不是逐细胞实测调谐。间歇节奏为每秒 350 ms，不代表真实求偶歌。没有声压、反射、载波锁相或物理声场模拟；音量百分比不是分贝。声音会影响连接组计算，但未假定固定的趋声或逃声行为。食物与声源几何仅为放大的感觉源标记，不作为实体碰撞物。

嗅觉 / 听觉读数来自实际计算出的群体平均脉冲率，按细胞数加权、110 ms 平滑；关闭源后残余突触活动与平滑读数可短暂保留。移动或调节刺激不会重置膜电位、时钟或放电历史。所选感受器没有原始胞体坐标，参与计算与栅格显示，但不在 3D 中补点。下游探针选取该输入群体突触权重总和最高、且有真实坐标的直接靶细胞；它是解剖采样点，不保证最活跃，也不代表整个通路。

这是全量连接组上的点神经元 LIF 模型。每个纳入的神经元都有膜电位、突触电流和不应期；计算以 0.2 ms 步长推进，连接传递延迟为 1.8 ms。工作线程独立计算，画面显示每个神经元上次放电距当前模拟时间的间隔。放电后的光晕仅用于放慢视觉消退，不产生额外事件。

参数参考 Shiu 等的果蝇全脑 LIF 模型：静息/复位电位 −52 mV、阈值 −45 mV、膜时间常数 20 ms、突触时间常数 5 ms、不应期 2.2 ms、每个突触权重 0.275 mV。这些不是对 MaleCNS 每个细胞分别测得的参数。输入为选定类型的 Poisson 刺激，所有细胞保留不应期。

快速突触符号假设：乙酰胆碱兴奋；GABA 和谷氨酸抑制。受体特异性作用、神经调质、缺失的电突触、树突/轴突多分区、离子通道动力学和真实身体动力学均未建模；其他或未知递质的快速作用设为零。结构连接仍完整保留。此模型不能据此宣称还原真实感觉、行为或完整生物物理机制。

“逼近”“甜味”“机械”“光”是直接刺激对应注释类型的实验入口，尚未由自然刺激编码器或实验记录校准。静息网络无背景噪声；没有刺激时不放电也是模型结果。R1–R6 的快速递质作用未建模，该入口目前只能显示直接刺激的细胞，不能据此模拟完整视觉传播。

所有点均来自原始 somaLocation，单位为 8 nm 体素。缺少胞体坐标的神经元参与计算但不显示在脑图上。三维点云将三个坐标轴统一换算为微米，只做居中和刚体旋转，保持原始距离。点表示胞体，未显示树突或轴突形态；重叠不表示连接。没有将缺失坐标随机填入图中。
